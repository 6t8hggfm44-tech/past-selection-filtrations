# Past-Selection Filtrations — Continuous Research Workspace

An operator-algebraic research program on accessible quantum records, measurement, and temporal structure.

This repository also serves as the persistent state and audit trail for the PSF continuous-science agent.

## Agent workflow
1. Read `research-agent/CURRENT_MANUSCRIPT.json`, the referenced current manuscript, `research-agent/MANUSCRIPT_SYNC_2026-09-07.md`, and `PSF_RESEARCH_STATE.md` before assessing current claims.
2. Consult the literature, red-team, open-problem, and decision ledgers before repeating work.
3. Search literature and perform adversarial mathematical/physical review.
4. Update state only when evidence changes it.
5. Record uncertainty explicitly; never convert conjecture or interpretation into a proved result.
6. Preserve intellectual history through Git commits.

## State files
- `PSF_RESEARCH_STATE.md` — canonical current state
- `literature/LEDGER.md` — prior-art and adjacent-literature assessments
- `red-team/LOG.md` — adversarial attacks and outcomes
- `open-problems/QUEUE.md` — prioritized unresolved research problems
- `decisions/DECISION_LOG.md` — consequential research decisions and claim changes
- `research-agent/OPERATING_RULES.md` — standing instructions for agent runs
